# 🚀 100 Problems – 5 Languages

A coding challenge focused on strengthening **problem-solving, logical thinking, and programming fundamentals** by solving 100 unique coding problems in **5 different programming languages**.

## 💻 Languages

* 🐍 Python
* 🔵 C
* 🔷 C++
* ☕ Java
* 🟨 JavaScript

## 🎯 Goal

The goal of this challenge is not just to complete 100 problems, but to understand the **logic behind each problem** and learn how the same logic can be implemented in different programming languages.

### What I aim to improve

* Logical thinking
* Problem-solving skills
* Programming fundamentals
* Understanding of different programming syntaxes
* DSA fundamentals
* Writing clean and efficient code

## 📌 My Approach

For every problem, I will try to:

1. Understand the problem
2. Develop the logic
3. Write the solution
4. Test it with different inputs
5. Implement the same logic in different languages
6. Analyze time and space complexity
7. Document what I learned

## 🔥 Challenge Rule

This is a **100-problem challenge**, not a strict 100-consecutive-day streak.

If I take a break, I will continue from where I stopped instead of starting over.

> **Break is okay. Quitting is not. 🚀**
